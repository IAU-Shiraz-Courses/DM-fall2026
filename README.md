# 📊 Data Mining Course Website — Fall 2026

Official web repository for the **Data Mining** undergraduate course at **Islamic Azad University (IAU), Shiraz Branch**, taught by **Dr. Amin Eskandari**.

---

## 📌 Overview

This repository contains the source code for the official course website. The platform serves as the central hub for students to access syllabus details, lecture materials, assignments, dataset links, and course announcements throughout the term.

- **Course Title:** Data Mining
- **Instructor:** Dr. Amin Eskandari
- **Term:** Fall 2026 (16 Weeks)
- **Credits:** 3 Units
- **Primary Reference:** _Data Mining: Concepts and Techniques (DMCT)_ — Jiawei Han, Micheline Kamber & Jian Pei

---

## 🗺️ Course Topics

The course covers the end-to-end **Knowledge Discovery in Databases (KDD)** pipeline:

1. **Introduction & KDD Overview** — Foundations of data mining and pattern discovery.
2. **Data Preprocessing & Cleaning** — Feature scaling, handling missing values, and data reduction.
3. **Frequent Pattern Mining** — Association rule mining (Apriori, FP-Growth).
4. **Classification & Machine Learning** — Decision trees, Naive Bayes, KNN, and evaluation metrics.
5. **Clustering** — Partitioning methods (K-Means), hierarchical clustering, and DBSCAN.
6. **Advanced Topics & Outlier Detection** — Anomaly detection algorithms and modern applications.
